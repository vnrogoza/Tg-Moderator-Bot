# Руководство по запуску Telegram AI Модератора (Python Backend)

Этот проект состоит из двух взаимосвязанных частей:
1. **Python / FastAPI сервер + Gemini 3.8 AI**: обрабатывает сообщения, выставляет оценки от -5 до +5, следит за кармой, мутит нарушителей и слушает Telegram Long Polling / Webhook.
2. **React + Tailwind веб-панель администратора**: интерактивный симулятор чата, база пользователей, карма, статистика и аналитика в реальном времени.

---

## Вариант 1. Запуск прямо сейчас в AI Studio (Облачная среда)

Проект **работает на Python сервере**:
- **Адрес панели:** откройте текущую вкладку превью.
- Во вкладке **«Чат & Симулятор»** вы можете:
  - Писать любые фразы в поле ввода внизу и нажимать `Enter` (или кликать по кнопкам быстрого теста: *Мат и токсичность*, *Оскорбление*, *Вопрос*, *Конструктив*).
  - Переключать участников (*Вы*, *Дмитрий-Тролль*, *Алексей-Эксперт*, *Анна-Позитив*).
  - Наблюдать, как бот выставляет оценки под каждым сообщением, перечеркивает удаленный мат и применяет автоматический мут при падении кармы ниже -10.

## Вариант 2. Запуск на собственном сервере (VPS / VDS / Ubuntu / Debian)

### 1. Требования
- Python 3.10 или выше (`python3 --version`)
- pip (`pip3 --version`)
- Node.js 20+ для сборки веб-панели (`node -v`)
- Токен бота из Telegram [@BotFather](https://t.me/BotFather)
- Ключ Google Gemini API (`GEMINI_API_KEY`) из [Google AI Studio](https://aistudio.google.com/)

### 2. Установка зависимостей
```bash
# Установка Python пакетов
pip3 install -r requirements.txt

# Установка зависимостей фронтенда
npm install
```

### 3. Настройка переменных окружения (.env)
Создайте файл `.env`:
```env
PORT=3000
GEMINI_API_KEY=ваш_ключ_gemini
TELEGRAM_BOT_TOKEN=ваш_токен_из_BotFather
```

### 4. Сборка и запуск
```bash
# Сборка фронтенда
npm run build

# Запуск Python сервера
python3 server.py
```

Для непрерывной работы в фоне через `pm2` или `systemd`:
```bash
# Запуск через pm2
pm2 start "python3 server.py" --name "tg-ai-moderator"
pm2 save
pm2 startup
```

## Вариант 4. Запуск через Docker

```bash
docker build -t tg-ai-moderator .
docker run -d -p 3000:3000 \
  -e GEMINI_API_KEY="ваш_ключ" \
  -e TELEGRAM_BOT_TOKEN="ваш_токен" \
  --name telegram-bot tg-ai-moderator
```

## Настройка Telegram Webhook (опционально)

По умолчанию бот использует надёжный **Long Polling**, не требующий белого IP или домена.
Если вы хотите использовать **Webhook**:
1. Откройте в веб-панели вкладку **«Настройки»** -> **«Telegram Бот»**.
2. Введите URL вашего сервера (например `https://your-domain.com/api/telegram/webhook`) и нажмите **«Установить Webhook»**.
3. Добавьте бота в группу Telegram и сделайте его **Администратором** с правами:
   - *Удаление сообщений*
   - *Блокировка пользователей*
